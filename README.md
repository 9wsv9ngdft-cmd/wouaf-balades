# 🐾 Wouaf Balades

Une web app toute simple pour trouver des balades à faire avec son chien autour de soi.

**👉 https://9wsv9ngdft-cmd.github.io/wouaf-balades/**

Sur iPhone : ouvrir le lien dans Safari → bouton Partager → « Sur l'écran d'accueil ».

## Ce qu'elle propose

- Sentiers balisés (itinéraires de randonnée et promenade OpenStreetMap), avec GPX via Waymarked Trails
- Parcs à chiens, forêts, bois, prairies, parcs, plages autorisées aux chiens
- Points d'eau, distributeurs de sacs, plans d'eau à proximité
- Lieux marqués « chiens interdits » ou privés exclus
- Classement selon la distance, la durée voulue et l'envie de liberté
- Favoris enregistrés sur le téléphone

## Données

© contributeurs OpenStreetMap (ODbL), via l'API Overpass et Nominatim. Aucune clé, aucun compte, aucun serveur : un seul fichier `index.html`.
